FAQ

Frequently asked questions about scaled learning and AI.

Short answers on scaled learning, the learning organization, AI-driven OKRs and scorecards, governance, Kaizen events, planning, value streams and knowledge management. Each links to a fuller guide.

What is scaled learning?

Scaled learning is the practice of building an organization so that learning grows as more people take part. People learn by doing real work, peers share what works, the know-how is captured, and AI agents use it to handle routine work. Read the full scaled learning guide.

How is scaled learning different from training?

Training pushes approved content from a few people to many. Scaled learning also treats everyday work as a source of knowledge: what a team learns is captured and made findable so others can reuse it.

What is a learning organization?

A learning organization builds learning into daily work through routine reflection, curiosity from leaders, small safe experiments, captured knowledge and peer teaching. See the learning organization guide.

What are AI-driven OKRs?

AI-driven OKRs use AI to help draft, critique, track and learn from objectives and key results, while people decide what matters and how ambitious to be. See the AI-driven OKRs guide and the book AI-Driven OKRs.

Can AI write my OKRs for me?

AI is useful for producing several draft options and for critiquing them, for instance spotting key results that are really tasks. Choosing priorities and setting the level of ambition should stay with your team.

What is an AI-driven balanced scorecard?

It is a balanced scorecard, with financial, customer, process and learning perspectives, kept current with data and agents that refresh measures and help explain changes. People still choose the measures and interpret them. See the guide.

What is the difference between AI governance and data governance?

AI governance covers how models and agents are used: purpose, risk, oversight and monitoring. Data governance covers the data behind them: ownership, lineage, privacy and quality. They work best as one system. See the AI and data governance guide.

What is a Kaizen event?

A Kaizen event is a short, facilitated improvement sprint in which the people who do a process map it, find waste, test changes and put the working ones in place. See Kaizen events for AI-enabled work.

How long does a Kaizen event take?

Events commonly run between two and five days, depending on the size of the process and how many of the right people can attend. Follow-up reviews after the event are part of the work.

What is AI-driven PI planning?

PI planning is a multi-team planning event, often held each quarter. AI-driven PI planning uses agents to prepare briefings, check dependencies and follow up, while the planning conversation stays with people. See the guide.

What is a value stream identification workshop?

It is a facilitated session where leaders and practitioners name the value streams that deliver value to customers, sketch their steps, people and systems, and find where to improve or add AI agents. See the value stream guide.

How do AI agents help with knowledge management?

Agents can draft notes from retrospectives, tag and file them, and answer questions from approved sources with citations. They only work well when the knowledge has owners and review dates. See knowledge management with AI agents.
